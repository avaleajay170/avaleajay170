## 🧠 DocIntegrity AI
**AI-Powered Assignment Integrity Verification**

`Django` `Python` `MySQL` `PyTorch` `OCR` `GPTZero API`

A web platform designed to verify assignment authenticity through a combination of **handwriting verification and AI-content detection**.

**Highlights**
- Built a **Siamese Neural Network** using the IAM Handwriting Database and a custom student handwriting dataset.
- Achieved **97% validation accuracy** on handwriting verification.
- Integrated OCR for text extraction.
- Integrated the GPTZero API to detect potential AI-generated content.
- Provides handwriting-match and AI-content scores for verification. citeturn2file0
